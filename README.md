## 维护

这是无第三方依赖的静态网站。GitHub Pages 从 `main` 分支根目录发布。
修改中英文 HTML 后检查链接、邮箱和隐私说明，提交并推送即可更新。
发布说明按实际上传的构建描述功能；源码已实现但尚未上传的改动不列为该构建已发布功能。上架可用性以 App Store 显示为准。
请勿将 App 源码、凭据、真实照片或私人日志放入本仓库。
